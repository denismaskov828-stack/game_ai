YG REMASTERED v1.0
==================

WINDOWS
-------
Запуск: Yg Remastered.exe
Один файл, установка не требуется.
Требования: Windows 7 / 8 / 10 / 11, 64-bit, OpenGL 2.1.
Сохранения: %APPDATA%\Godot\app_userdata\Yg\savegame.json

УПРАВЛЕНИЕ
----------
WASD / стрелки   — движение
Пробел           — прыжок (короткая неуязвимость)
E / Shift        — фазовый сдвиг (уровень 8)
Esc              — пауза
На телефоне: джойстик слева, прыжок справа, кнопки «ФАЗА» и «II».

УРОВНИ
------
0  Туториал
1  Первый контакт
2  Минное поле
3  Разлом
4  Босс: Пушка
5  Обратный мир
6  Схема        — отключение энерготерминалов
7  Импульс      — прыжковые платформы и сбор ядер
8  Фаза         — фазовый сдвиг и выживание 45 секунд

Новые уровни 6–8 открыты сразу из меню.

БРАУЗЕРНАЯ ВЕРСИЯ (HTML5)
-------------------------
Запуск: run_web.bat
Скрипт поднимает локальный HTTP-сервер и открывает игру в браузере.
Просто открыть web/index.html двойным щелчком нельзя — WebAssembly
требует HTTP. Папку web можно также разместить на любом веб-сервере.

ИСХОДНЫЙ ПРОЕКТ
---------------
Папка с проектом Godot 3.5.2: ..\yg_remastered
Исходная игра не изменялась.
